# Narrativa de carreira

## Trajetória

Minha paixão por tecnologia nasceu com computadores e jogos. Comecei meus estudos formais em 2022 no Técnico de Informática integrado ao Ensino Médio no IFSP. Foi lá que dei os primeiros passos com Python, HTML, CSS e JavaScript, apaixonando-me de cara pelo ecossistema Frontend.

A partir de 2024, consolidei meus conhecimentos fazendo meus primeiros projetos reais como freelancer, envolvendo React e integrações com backends em Java Spring Boot. No ano seguinte (2025), entrei na faculdade de Análise e Desenvolvimento de Sistemas (também no IFSP) para formalizar e estruturar meus conhecimentos, e logo consegui minha primeira oportunidade profissional como Desenvolvedor Full Stack na StarSeg. Lá, passei a utilizar o stack moderno do ecossistema JavaScript (Next.js e Node.js), além de atuar fortemente em todo o ciclo de vida do software, envolvendo Docker, GitHub Actions, CI/CD e decisões arquiteturais.

## Onde quero chegar

Hoje, estou em uma jornada forte para consolidar minhas habilidades em Backend corporativo e alta escalabilidade. Meus estudos atuais estão concentrados em Java Spring Boot, Angular e ecossistemas de nuvem e DevOps (AWS, Azure, Terraform, Kubernetes, Datadog). 

No médio prazo, pretendo realizar uma Pós-Graduação em Arquitetura de Software. Meu objetivo é dominar conceitos avançados de System Design e diferentes arquiteturas (Domain-Driven Design, Arquitetura Hexagonal, Arquitetura em Camadas, etc.) para desenhar, liderar e sustentar produtos complexos que exigem extrema resiliência e solidez.
